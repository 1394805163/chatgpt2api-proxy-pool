# chatgpt2api v1.7 运行版整合实现计划

> 面向 AI 代理的工作者：按小步测试、实现、验证；官方 v1.7 冲突处优先保留官方修复，本地独有功能单独迁移。

**目标：** 以官方 `v1.7.0` 为底座，保留既有生图队列、额度、设置持久化、图片留存、账号刷新防卡死与免刷新导入，移除注册浏览器和 Render/Neon 强依赖，并将运行存储切换为 SQLite WAL。

**架构：** chatgpt2api 只承担账号池、生图和 OpenAI 兼容 API。注册发生在独立注册机；注册机测活成功后通过管理员接口推送完整账号对象。账号池确认死亡后按既有策略删除，限流和网络错误只标记。

**技术栈：** Python 3.13、FastAPI、SQLAlchemy、SQLite WAL、Next.js、Docker Compose。
